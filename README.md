# Kanjigation Quest!
こんにちは！
This is a project that I made in my spare time to help practice techniques that I struggle to learn in Japanese. Right now it contains support for a number of common conjugated forms for beginner level Japanese. 
- Polite and Standard forms,
- Past and Negative Forms,
- Verbs, Adjectives, and Nouns
- Genki 1 Vocabulary up to chapter 5.
- And more!

**Adventure Mode**: fight monsters by successfully completing conjugation tasks. Can you beat the ラスボス?

**Quiz Mode**: Decide how many questions you want to do and what conjugations you want to be quizzed on. Receive a grade at the end
